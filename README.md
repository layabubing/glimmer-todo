# Glimmer Todo · 浮光待办

Windows 桌面悬浮待办、日程与番茄钟工具，使用 C++20、Direct3D 11 和自绘界面。支持 Windows 10 1703 及以上版本、Windows 11，要求 x64 系统。界面通过 Windows 内置 WARP 软件绘制，使用系统微软雅黑和 Segoe UI Emoji 字体。

产品宣传片展示 v1.4.2 的界面与性能数据，时长 36 秒，提供 [4K 60 FPS 视频](promo/glimmer-todo-4k60.mp4) 和支持章节跳转的 [离线网页](promo/index.html)。

## 下载

从本仓库的 Releases 页面下载 `GlimmerTodo-v1.10.0-windows-x64.zip`，解压后双击 `GlimmerTodo.exe` 运行。

默认窗口为 260 × 300，最小可调整至 240 × 200；尺寸使用 Windows 逻辑像素。界面采用紧凑标题栏、分段导航、单行待办列表和底部输入区域，待办数量显示在标题旁边。窗口尺寸可以调整并自动保存。从 v1.5.0 升级时应用紧凑尺寸，保留已有位置与数据。

通过窗口内的“待办 / 日程 / 专注”按钮切换功能，也可以聚焦导航后使用左右方向键。切换页面时，导航背景滑动，页面内容轻微移入，动画持续约 180 毫秒；系统关闭界面动画时，程序同步关闭切换动画。内容超出窗口时可滚动查看。

按钮、输入框、列表、开关、选择器、日历、文件浏览、菜单、确认窗口和信息提示均由应用绘制。输入支持中文输入法、复制粘贴和键盘导航，界面随 Windows 屏幕缩放调整。

## 外观主题

点击右上角调色板图标，或进入设置中的“外观主题”，选择“晨光 · 浅色”“夜色 · 深色”或“森林 · 绿色”。主题会立即应用到主窗口、设置、日程编辑器、文件浏览与收起窗口，并自动保存。专注页面集中显示倒计时、进度和今日完成次数。

在设置中的“字体比例”选择 80%～150%，每档相差 10%，默认 100%。修改立即应用到各个页面、编辑窗口、菜单、信息提示及收起窗口，并自动保存。窗口尺寸保持原来的设置，内容较多时可以滚动查看。

## 批量导入任务

点击待办页面底部的“导入”，或按 Ctrl+I，打开自绘导入窗口。粘贴多行文字，每行生成一条待办，空行自动忽略，保留原有顺序和重复内容。点击“导入任务”或按 Ctrl+Enter 一次保存全部任务。

每条任务最多 500 个 UTF-16 字符。出现超长内容时显示行号，修改后可以重新导入。整批内容检查通过后一起保存；关闭导入窗口会保留本次草稿。导入窗口随游戏自动隐藏，并支持跟随虚拟桌面。

## 开机自启

右键系统托盘图标，点击“开机自启”，或在设置顶部切换“开机自启”。两个入口共用 Windows 启动项的状态，开启后在当前用户登录 Windows 时自动启动浮光，关闭后移除启动项。默认关闭，无需管理员权限。

开启时记录当前 EXE 的完整路径，路径包含空格或中文时也可以使用。移动程序后，请重新关闭并开启一次开关，以更新启动路径。

## 收起模式

在“设置 → 收起模式”选择默认形式，再点击标题中的“收起”或关闭窗口。右键主窗口空白处、收起窗口或托盘图标，通过“收起模式”菜单选择形式并立即收起。

| 模式 | 显示内容与操作 |
| --- | --- |
| 胶囊 | 304 × 66 的两行窗口，显示已完成 / 全部待办、番茄钟倒计时和最近日程。拖动空白区域移动，位置自动保存。 |
| 屏幕顶部长条 | 位于主窗口所在屏幕的工作区顶部，宽度最多 720、高度 46，横向展示待办、番茄钟和日程。随屏幕可用空间调整尺寸。 |
| 完全隐藏 | 隐藏主窗口和收起窗口，保留系统托盘图标与提醒。 |
| 任务栏 | 在 Windows 任务栏左侧空白区域显示两行信息：待办完成进度、番茄钟倒计时和最近日程。点击信息面板展开，右键打开菜单，悬停查看完整内容。 |

尺寸使用 Windows 逻辑像素。胶囊和长条跟随当前主题及置顶设置，悬停空白区域可查看完整信息；点击“展开”或双击空白区域恢复完整窗口。所有模式都可以通过双击托盘图标或再次运行 EXE 展开。托盘悬停提示也会展示基本信息。

任务栏信息面板宽度为 152、高度最多 42，随任务栏缩放并跟随当前主题，附属于 Windows 主任务栏。任务栏图标居中排列时使用左侧空白区域；空间不足或任务栏暂时不可用时隐藏面板，空间恢复后自动显示。托盘图标持续提供展开入口。

游戏或指定软件进入前台时，主窗口、收起窗口和任务栏信息面板都会隐藏；切换离开后恢复之前的展开或收起状态。收起窗口支持跟随 Windows 虚拟桌面，切换模式保留主窗口的位置与尺寸。模式选择自动保存，重新启动后从完整窗口开始。

## 日程

- 在“日程”页面点击“新增日程”，填写内容，通过日历或年、月、日输入框选择本地日期，填写小时与分钟，可选择每天或每周重复。
- 日程按时间排序；双击文字或按 F2 编辑，点击左侧方框完成，点击右侧删除按钮或按 Delete 删除。
- 重复日程完成后推进到下一个未来日期，保留本地时刻；一次性日程可以完成或恢复。
- 到时通过系统托盘提醒。游戏或指定软件处于前台时延后提醒，切换离开后按顺序显示。
- 应用需要保持运行；退出后错过的未提醒日程在下次启动时提醒。Windows 通知设置可能影响提醒的展示与声音。

## 番茄钟

“专注”页面默认专注 25 分钟、短休息 5 分钟、每完成四次专注进入 15 分钟长休息。每个阶段结束后提醒，并等待点击“开始”进入下一阶段。

支持开始、暂停、继续、重置和跳过。重置从新一轮专注开始；跳过阶段不增加完成次数。今日完成次数按本地日期统计。

使用计时按钮下方的下拉菜单绑定未完成的待办。专注页面显示已绑定的任务，待办条目显示番茄钟图标。完成或删除该任务会解除绑定，当前计时继续运行。绑定会在重启后恢复，也可以在下拉菜单中主动解除。

暂停后展开“计时设置”，可调整时长：专注 1–180 分钟、短休息 1–60 分钟、长休息 1–120 分钟，点击“保存时长”应用。运行中的截止时间自动保存，休眠或重启后继续按实际经过的时间计算；错过截止时间时完成当前阶段，下一阶段等待手动开始。

## 更新

每次启动时，应用都会在后台检查 GitHub 最新正式版本。发现更新时会在系统托盘提醒，指定软件处于前台时延后提醒。可在“设置”的“应用更新”中查看结果或手动检查。

点击“下载新版本”，下载完成并通过 SHA256 校验后，点击“安装并重启”并确认。程序从 `layabubing/glimmer-todo` 的最新正式 GitHub Release 获取 `GlimmerTodo.exe` 附件及其摘要。

检查和下载在后台执行。更新助手等待旧进程退出后替换程序并启动新版本；数据保留在原本的本地目录。程序目录需要具备写入权限，更新前的 EXE 保存在同目录的 `.previous` 文件中。`.glimmer-update` 目录存放更新助手与下载文件。

## 使用

- 在底部输入待办，按 Enter 或点击加号保存。每条待办最多 500 个 UTF-16 字符。
- 右键待办可添加或编辑多行笔记，每条笔记最多 8192 个 UTF-16 字符。有笔记的待办会显示笔记图标，点击图标可以直接打开。清空笔记后保存即可移除。
- 新增或编辑待办时，点击底部的日历图标调整 0–100 的优先级和可选的截止日期，点击“确定”后保存待办。右键已有待办并选择“设置优先级和截止日期”，点击“确定”即可保存设置。未完成的待办从截止日期的次日开始显示逾期。
- 番茄钟绑定的待办排在最前，其他未完成待办按优先级数值从高到低排列，已完成待办放在底部。同组同分的待办按创建顺序排列。新建和批量导入的待办默认为 50，旧版的低、普通、高分别转换为 25、50、75。
- 点击左侧方框完成或恢复待办。双击待办文字或选中后按 F2 编辑；编辑时按 Esc 取消。
- 右键待办条目可以编辑、完成、恢复或删除该条待办。点击右侧删除按钮或选中后按 Delete 也可以删除待办。
- 右键主窗口空白处或托盘图标，可以清理全部已完成待办。
- 拖动窗口顶部移动位置，拖动边缘调整大小。位置、尺寸和置顶选项自动保存。
- 点击右上角设置图标，管理自动隐藏和置顶选项，启用需要检测的软件。设置内容可以滚动查看。
- 在设置中输入进程文件名，例如 `notepad.exe`，点击“添加”；也可以通过“从程序文件选择…”打开自绘文件浏览窗口，选择实际运行的主程序。支持中文路径、搜索与磁盘切换。
- 点击“收起”或关闭窗口，使用设置中选择的收起模式。双击托盘图标，或者再次运行 EXE，可以显示已有窗口。右键托盘图标可以退出。
- Ctrl+N 聚焦新增待办输入框。列表支持方向键、Space 完成切换、Enter 编辑和 Tab 切换控件。

自动隐藏按当前前台窗口所属的 EXE 文件名匹配，忽略英文大小写。已添加的软件进入前台时，待办、设置和程序选择窗口隐藏；软件进入后台、最小化或退出后恢复显示。恢复显示使用不激活窗口的方式，保留当前程序的键盘焦点。手动收起后保持收起状态，直到主动显示。

切换 Windows 虚拟桌面后，待办及已打开的设置窗口会跟随当前桌面。各个桌面共用待办和软件规则，自动隐藏根据当前桌面的前台程序生效。程序保留输入框内容、窗口位置与手动收起状态。

选择软件时，请选择实际运行程序；使用独立启动器的软件，需要添加运行后的程序文件名。相同文件名的软件共用检测规则。

## 本地数据

待办、日程、番茄钟和设置保存到 `%LOCALAPPDATA%\DesktopList\state.json`。每次修改立即写入文件，刷新到磁盘后原子替换正式文件。可以在退出应用后复制该文件备份。检查和下载更新需要联网。

前台检测使用 Windows 前台切换与窗口隐藏事件通知，每 250 毫秒检查一次当前状态。程序保持单个实例运行。

## 编译与测试

本项目附带 nlohmann/json 3.12.0、Dear ImGui 1.92.3 与 ImGuiFileDialog 0.6.8 的源码及 MIT 许可。编译环境使用 w64devkit 2.11.0；安装脚本从官方发布地址下载，并检查 SHA256。环境保存在项目的 `.tools` 目录。界面依赖在本地编译，首次构建会生成静态归档。

在项目目录的 PowerShell 中执行：

```powershell
.\setup.ps1
.\build.ps1
```

生成文件为 `build\GlimmerTodo.exe`。可以通过 `./build.ps1 -Test` 运行数据逻辑、自绘交互及窗口模式检查；界面检查在独立隐藏桌面中执行真实 Direct3D 绘制，覆盖三套主题、中文输入、键盘提交、日期校验和四种收起模式，并确认没有可见原生子控件。渲染图保存在 `.work\ui-renders`。任务栏检查使用真实任务栏窗口；其他前台窗口遮挡面板时会报告屏幕像素检查暂不可用。通过 `./package.ps1` 生成 `dist` 中的发布文件。运行程序后执行下列命令，可以采样内存、CPU 时间和句柄数量：

```powershell
.\tests\measure.ps1 -DurationSeconds 60
```

采样报告保存在 `.work\memory.json`。指标使用 MB，即 1,000,000 字节。采样期间总工作集超过 50 MB 时，脚本报告测试失败。自绘界面在本机任务栏模式下的专用工作集约 43 MB，总工作集约 103 MB，包含 Windows 图形组件与字体映射；当前版本未达到总工作集 50 MB 的目标。界面隐藏时暂停图形绘制，番茄钟持续按实际时间计算。
